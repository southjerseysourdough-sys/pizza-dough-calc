## Verified registry commands

Spotlight Card is already installed locally; no reinstallation is required. Its exact official command is:

```bash
corepack pnpm exec shadcn add @react-bits/SpotlightCard-TS-TW --path src/components/effects
```

Perspective Grid is verified at the exact registry entry `perspective-grid`. The install command for this project is:

```bash
corepack pnpm exec shadcn add @vengeanceui/perspective-grid
```

No other React Bits or Vengeance UI component is planned for this phase.
